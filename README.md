# Sci-Fi Site

Sci-Fi Site is a futuristic, interactive web project that combines a stylized portfolio experience with a collection of small digital tools. The site is designed with a neon sci-fi aesthetic and features several utility pages built as part of a creative web experience.

## Overview

This website acts as a hub for different online tools and mini-projects. Each section is designed to feel like part of a larger sci-fi terminal interface, giving the whole site a cohesive and immersive look.

## Included Tools

The site currently includes:
- Calculator
- Password Generator
- AI Chatbot
- Adblocker Extension Page

## Features

- Futuristic sci-fi visual design
- Clean and modern layout
- Multiple interactive web tools
- Responsive page structure
- Simple navigation across the site

## Tech Stack

This project uses:
- HTML
- CSS
- JavaScript

## How to View the Project

You can visit the live project at https://www.sci-fi.site/

## Project Structure

The website is organized as a collection of individual pages and tool folders, each with its own HTML, CSS, and JavaScript files.

## Notes

This project is designed as a personal portfolio-style website with creative visual direction and small functional tools. It is meant to feel polished, experimental, and memorable.
