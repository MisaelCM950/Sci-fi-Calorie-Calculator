Sci-Fi Ad blocker

This Chrome extension blocks intrusive ads and trackers so your browsing feels faster and cleaner. It works by hiding known ad elements and stopping common tracking scripts.

Install Instructions

  1. Download or unzip the extension folder to your computer.
  2. Open Chrome and go to chrome://extensions.
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select the Adblocker folder.
  5. The extension will appear in Chrome and should be ready to use.
